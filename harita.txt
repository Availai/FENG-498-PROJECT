════════════════════════════════════════════════════════════════════════════
 0. ÖZET — NE YAPAR, KİME YAPAR
════════════════════════════════════════════════════════════════════════════

Smart Agri, Türk çiftçileri için offline-öncelikli bir akıllı tarım
asistanıdır. Uydu haritası üzerinde tarla poligonu çizilir; tarlaya ürün
atanır; uygulama o tarlaya özel hava, toprak, NDVI, sulama, hastalık/zararlı
ve münavebe uyarılarını üretir. İnternet yoksa son bilinen hal gösterilir
ve işlemler outbox'a düşer; internet dönünce senkron olur.

Tasarım felsefesi:
  • "Cüzdan-defter" kültürüne uyumlu sade arayüz (krem/yonca yeşili).
  • LLM yok — tüm tarım kararları deterministik kural motoruyla.
  • Çiftçinin 3G'si yokken bile en temel bilgiyi görebilmesi (offline cache).
  • Ücretli API bağımlılığı minimum — birincil hava servisi Open-Meteo
    (anahtarsız, ücretsiz).

Tipik veri akışı (örnek: "Tarla ekle → risk analizi gör"):

  1. Kullanıcı map_hub_screen veya field_detail_screen üzerinde poligon çizer
  2. LocalDataRepository.upsertFieldFromLegacyMap → Drift `fields` tablosu
  3. SyncRepository.enqueueJob → SyncJobs outbox satırı
  4. Dashboard / field_detail açılır → agri_service + unified_weather_service:
        Open-Meteo (current+daily)  →  OWCurrentWeather/OWForecast objesi
        SoilGrids                   →  pH
        (opsiyonel) Agromonitoring  →  NDVI, toprak nem
  5. RuleEngine.analyze(...) (lib/services/rule_engine.dart) deterministik
     kurallarla risk listesi döner → ekranda kart/uyarı olarak gösterilir
  6. Sık görülen uyarılar: NotificationService.show(...) ile local notif
  7. Ağ varsa SyncService.runForegroundSync → backend /api/sync/push
  8. Android'de WorkManager periyodik: her 3 saatte bir hava + don taraması

 ─── (B) HIVE KV  (hızlı cache, legacy UI state, küçük listeler) ────────
   main.dart'ta açılan 9 kutu ve amacı:
     agri_history        → geçmiş kısa ortam analizleri (dashboard trend)

                             tutulan ama widget'ların izlediği mirror)
     recognized_plants   → kamera ile tanınan bitki geçmişi

                             ve ağdan gelen Perenual kayıtları)

     sim_results_cache   → agri_sim_service sonuçları
     sensor_data         → cihaz/BLE sensör kayıtları
     cost_ledger         → ÇKS masraf defteri kalemleri
     crop_history        → münavebe geçmişi (field_id → [ürün])
   Önemli: 'user_crops' hâlâ canlı — Drift gerçek kaynak, Hive UI için
   mirror ediliyor (LocalDataRepository._mirrorActiveFieldsToHive).

 ─── (C) POSTGRESQL + POSTGIS (backend, tüm çiftçilerin paylaştığı DB) ──
   Dosya: database/schema.sql
   Tablolar:
     farmers(id, firebase_uid UNIQUE, full_name, phone)
     fields(id, farmer_id, name, area_dekar, boundary GEOMETRY(Polygon,4326))
     field_analyses(id, field_id, crop_name, suitability_score, ai_report)

   gönderir, backend ST_GeomFromText(..., 4326) ile kaydeder. Listelerken
   ST_Centroid + ST_X/ST_Y ile merkez koordinat döner.

 Senkronizasyon: istemcide SyncJobs tablosuna düşer, SyncService

 5. KURAL MOTORU (RULE ENGINE) — PROJENİN KALBİ
════════════════════════════════════════════════════════════════════════════

 İki dilde birebir aynı mantık paralel tutulur (deterministik):
   • Python:  backend/rule_engine.py          (1038 satır)
   • Dart:    lib/services/rule_engine.dart   (1082 satır)

 Dart tarafı offline kullanım için; Python tarafı backend ekstra verilerle
 tutarlı aynı çıktıyı üretir. Her iki tarafta da kural sonuçları
 `{level, category, title, message, recommendation, emoji}` şemasındadır.

 5.1. Ortak kategoriler (RuleCategory)
 ──────────────────────────────────────
   disease        Hastalık (EPPO kodlu)
   pest           Zararlı (EPPO kodlu)
   irrigation     Sulama
   soil           Toprak pH/sıcaklık
   weather        Hava (sıcaklık, rüzgar, yağış)
   season         Mevsim/ekim zamanı
   compatibility  Bitki-tarla uyumu
   harvest        Hasat zamanı
   geography      ★ Türkiye enlem/eğim/bakı    (sadece backend)
   frost          ★ MGM zirai don              (sadece backend)
   rotation       ★ Münavebe geçmişi           (sadece backend + Flutter
                     lib/services/crop_rotation_advisor.dart ayna servis)

 5.2. EPPO Global Database referansı
 ──────────────────────────────────────
   rule_engine.py başında EPPO_CODES haritası var (resmi AB taksonomi).
   Örnek: BOTRCI=Botrytis, TUTAAB=Tuta absoluta, PUCCST=sarı pas.
   RuleResult.eppo_code alanı kural sonucuna eklenebiliyor.

 5.3. analyze() akışı (backend, tek çağrı 12 kural grubu)
 ──────────────────────────────────────
   _weather_rules(temp, avg_temp, humidity, weekly_rain, wind, precip_prob)
   _irrigation_rules(ndvi, soil_moisture, weekly_rain, precip_prob, plant, T)
   _disease_rules(name, temp, humidity, weekly_rain, soil_moisture, month)
   _pest_rules(name, temp, humidity, wind, month)
   _soil_rules(ph, soil_temp, plant, month)
   _season_rules(name, month, plant)
   _compatibility_rules(temp, avg_temp, ph, weekly_rain, humidity, plant)
   _harvest_rules(name, plant)
   ─── Türkiye'ye özgü (sadece backend'de) ───
   _turkey_geography_rules(lat, lon, slope_deg, aspect_deg, month)
       → Cooper 1969 deklinasyon + yamaç kosinüs yasası
       → Karadeniz kuzey yamaç uyarısı, Güneydoğu güney yamaç dikkati
       → Türkiye bbox: 35.5-42.5°K, 25.5-45°D dışında skip.
   _diurnal_stress_rules(lat, lon, min_c, max_c, month, name)
       → _is_central_anatolia(lat, lon): 37.5-40.5°K, 31-37°D
       → İç Anadolu bahar/yaz ≥20°C diurnal → hassas ürünlere (domates,
         biber, üzüm, fasulye, patlıcan) stres uyarısı
   _agricultural_frost_rules(lat, min_c, forecast_min_3day_c, month, name)
       → MGM eşikleri: ≤0 kritik, 0-2 uyarı
       → Bahar geç donu (Nis-May) + sonbahar erken donu (Eki-Kas)
   _crop_rotation_rules(crop_history, current_name)
       → 3 yıl üst üste tahıl → baklagil/ayçiçeği öner (Gaeumannomyces)
       → Solanaceae tekrarı uyarısı (Verticillium, Meloidogyne)
       → Ayçiçeği self-rotation → Sclerotinia sclerotiorum

   Sıralama: _SEVERITY_ORDER = critical < warning < info < ok

 5.4. Matematiksel çekirdek — rule_engine.py §685-734
 ──────────────────────────────────────
   _solar_declination_deg(m):   23.45·sin(360/365·(284+n))    [Cooper 1969]
   _day_length_hours(lat, m):   acos(-tan(lat)·tan(δ))·2/15
   _slope_sun_factor(lat, s, a, m):
        yamaç normali × güneş ışını kosinüsü  /  düz yüzey kosinüsü
        → eğim≥5° ise factor<0.75=warning, >1.25=info, arası ok

 5.5. Flutter tarafı yardımcısı (offline rotation advice UI için)
 ──────────────────────────────────────
   lib/services/crop_rotation_advisor.dart — CropRotationAdvisor.analyze()
   RotationAdvice(severity, title, message, suggestedCrops)
   3 kural: tahıl monokültürü, Solanaceae tekrarı, ayçiçeği self-rotation.

 6. DIŞ API'LAR — NEREDE KULLANILIYOR, NASIL ELE ALINMIŞ

 6.1. Open-Meteo  (BİRİNCİL HAVA SERVİSİ, anahtarsız, ücretsiz)
 ──────────────────────────────────────────────────────────────
   Base: https://api.open-meteo.com/v1/forecast
   Kullanan dosyalar ve amacı:
     lib/services/api/openweather_api.dart    (sınıf adı OWCurrentWeather
        geriye dönük uyum için korundu; iç implementasyon Open-Meteo)
     lib/services/agri_service.dart           (çoklu çağrı; dashboard,
        analiz, field-match akışları için current + daily)
     lib/services/unified_weather_service.dart (source label 'Open-Meteo')
     lib/services/notification_service.dart   (checkWeatherAndAlert —
        hourly temp/precip/wind, daily precip_sum; MGM/FAO/Beaufort eşikli)
     lib/services/frost_alarm_service.dart    (daily=temperature_2m_min,
        3 gün; sensibility months 4,5,10,11 + MGM 0/2°C eşikleri)
     lib/services/harvest_oracle.dart         (hasat tahmini için tarihsel)
     lib/services/local_data_repository.dart  (rapor için ek sorgular)
     lib/screens/dashboard_screen.dart        (özet kart + WMO→tr mapping)
     lib/screens/crop_field_match_screen.dart (tarla-ürün uyum)
   Parametreler genelde:
     current=temperature_2m,relative_humidity_2m,apparent_temperature,
             precipitation,weather_code,wind_speed_10m,wind_direction_10m
     daily=temperature_2m_min/max,precipitation_sum
     wind_speed_unit=ms, timezone=auto
   WMO weather_code → Türkçe tablo iki yerde: openweather_api.dart ve
   dashboard_screen.dart (_dashboardWmoCodeToTr).

 6.2. ISRIC SoilGrids v2  (toprak pH)
 ──────────────────────────────────────────────────────────────
   Base: https://rest.isric.org/soilgrids/v2.0/properties/query
   Sorgu: ?lon=..&lat=..&property=phh2o&depth=0-5cm&value=mean
   Sarmalayıcı: lib/services/api/soilgrids_api.dart (SoilGridsApi / SoilProfile)
   agri_service.dart içinde üç farklı akışta çağrılıyor.

 6.3. NASA POWER  (tarihsel hava/radyasyon — FAO ETo için)
 ──────────────────────────────────────────────────────────────
   Base: https://power.larc.nasa.gov/api/temporal/daily/point
   Kullanım: lib/services/agri_service.dart (uzun vadeli iklim metrikleri)

 6.4. MGM (Meteoroloji Genel Müdürlüğü)  — resmi istasyon verisi
 ──────────────────────────────────────────────────────────────
   Base: https://servis.mgm.gov.tr
   Sarmalayıcı: lib/services/api/mgm_api.dart (Origin/Referer header set)
   MgmStation, MgmObservation, MgmDailyForecast modelleri.

 6.5. Agromonitoring  (NDVI, toprak nem — OPSİYONEL, anahtar boşsa NO-OP)
 ──────────────────────────────────────────────────────────────
   Base: https://api.agromonitoring.com/agro/1.0
   Sarmalayıcı: lib/services/api/agromonitoring_api.dart
   agri_service.dart: _agroKey boşsa sessizce null döner, kullanıcıya
   hata gösterilmez (ücretli servis, herkes kullanmaz).

 6.6. Perenual  (bitki detay metadata)
 ──────────────────────────────────────────────────────────────
   Base: https://perenual.com/api/v2/
   İki tarafta da kullanılıyor:
     • lib/services/api/perenual_api.dart  + agri_service.dart
     • backend/agri_api.py (fetch_plant_details_from_perenual)
   Backend: /api/fields/{field_id}/plant içinde plants tablosunda yoksa
   Perenual'dan indirir → INSERT → analiz döner.

 6.7. PlantNet + Imagga  (kamera: foto → tür)
 ──────────────────────────────────────────────────────────────
   Flow (lib/services/agri_service.dart::analyzeImage):
     Aşama 1 (Imagga gatekeeper): "bu foto bitki/tarla mı?"
       https://api.imagga.com/v2/tags  (Basic auth — .env key+secret)
     Aşama 2 (PlantNet species ID):
       https://my-api.plantnet.org/v2/identify/all?api-key=$KEY
     Sonuç RuleEngine.analyze'a besleniyor.

 6.8. Backend (kendi FastAPI'miz)
 ──────────────────────────────────────────────────────────────
   Emulator base: http://10.0.2.2:8000 (env: BACKEND_BASE_URL)
   Uçlar (backend/main.py):
     POST /api/analyze/risks               → rule engine sunucu tarafı
     GET  /api/health                      → sağlık
     POST /api/sync/push                   → outbox LWW push
     GET  /api/sync/pull?since=…           → delta pull
     POST /api/fields/create               → WKT polygon + Firebase UID
     GET  /api/fields/{farmer_uid}         → çiftçi tarlaları (ST_Centroid)
     POST /api/fields/{field_id}/plant     → tarlaya bitki ekle + analiz
     POST /api/irrigation/schedule         → 7 gün FAO-56 Kc + ETo planı
     GET  /api/admin/users                 → admin listeleme
     GET  /api/admin/traffic               → admin istatistik
     GET  /admin                           → admin HTML paneli
     POST /api/admin/content               → ansiklopedi içerik güncelle
     POST /api/admin/broadcast             → FCM topic 'agri_alerts' push
   Auth: Bearer token (MVP: token = user_key). Üretimde Firebase Admin ile
   doğrulanacak not düşülmüş.

 6.9. .env dosyası (proje kökünde)
 ──────────────────────────────────────────────────────────────

11. ARKA PLAN / BİLDİRİM AKIŞI
════════════════════════════════════════════════════════════════════════════

 WorkManager (yalnız Android, diğer platformlarda no-op):
   periodicWeatherCheck (3h)
     → dispatcher: NotificationService.initialize
     → Drift'ten tüm tarlaları oku
     → her tarla için: NotificationService.checkWeatherAndAlert(lat,lon)
   periodicSyncFlush (1h)
     → SyncService ile outbox push

 Foreground tetikleme (dashboard_screen.dart::_triggerWeatherAlertIfDue):
   settingsBox['last_weather_check_at'] kontrolü (3 saat throttle)
   → NotificationService.checkWeatherAndAlert(lat, lng)
   → FrostAlarmService.checkAndNotify(lat, lng)

 Eşikler (notification_service.dart başında doküman + sabit):
   Don      ≤0°C kritik / ≤2°C uyarı       (FAO, WMO)
   Sıcak    ≥40°C kritik / ≥35°C uyarı     (FAO I&D Paper 66)
   Rüzgâr   ≥17.2 m/s kritik / ≥10.8 uyarı (Beaufort 8 / 6)
   Yağış    >50 mm/24h kritik / >20 uyarı  (MGM, WMO-No. 407)

 FCM topic 'agri_alerts' ile broadcast (admin paneli üzerinden).
